# Gallery video excerpts

These ten excerpts come from [yyyyywv/egocentric on Hugging Face](https://huggingface.co/datasets/yyyyywv/egocentric), retrieved on 2026-09-28. The source dataset declares [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) in its [README](https://huggingface.co/datasets/yyyyywv/egocentric/blob/main/README.md).

Credit: yyyyywv / egocentric. See `manifest.json` for the original path and download URL of each recording, SHA-256 verification, recording metadata, excerpt start time, and output details.

The excerpts retain the original playback speed. Processing consists of trimming to approximately 7–10 seconds, resizing to fit within 720 × 720 pixels without enlargement, encoding as H.264 at 24 fps, removing audio, and extracting a poster frame. No imagery was generated or added.

Labels describe the visible action. Embodiment labels use dataset metadata where available and the visible end effector otherwise. The `ego` recordings show human hands from an egocentric view. Source folder names are preserved in the manifest even where they differ from the descriptive gallery label.
